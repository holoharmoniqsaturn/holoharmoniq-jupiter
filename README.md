HoloHarmoniq Jupiter represents a fascinating intersection of artistry and technological visualization. Let's break down the credits, license, and core features that make this project special.

Credits and License
HoloHarmoniq Jupiter was created by the London-based company HoloHarmoniq Ltd. The project leverages the powerful three.js 3D engine, which is available under the permissive MIT license. While the visualization is immersive, it's important to note that the surface maps are artistic reconstructions inspired by the real moons, rather than standard mission imagery. Furthermore, distances and sizes are stylized to ensure all bodies are visible simultaneously. The HUD figures, such as radius, gravity, and distance, are standard published values. Users are encouraged to credit any specific source material, like NASA/JPL textures for Jupiter or mosaics of Io/Europa. The code license remains to be chosen before publishing, with MIT being a common option. The project carries the copyright of 2026 HoloHarmoniq Ltd and aligns with the principles of Science x Technology x Humanity.

Core Visualization Features
The project is packed with features designed for engagement and educational value. Key features include:

🪐 Juno Vision: A visualization of Jupiter featuring a soft atmospheric glow as it drifts among its moons.

🌋 Galilean Worlds: Detailed representations of Io, Europa, Ganymede, and Callisto, each with reconstructed surfaces and normal-mapped relief.

🔥 Io Plume: A stylized volcanic plume rising from the limb of Io.

🎬 Grand Tour: An autonomous, captioned flight (accessible by pressing REC) that takes the user past each moon in a 2:08 sequence.

🛰️ Landing Simulation: A feature allowing users to pick a moon for approach, descent, and low flyover, complete with a live HUD showing altitude, orbital speed, and position.

✨ 115 Moons: Detailed depictions of the four largest moons and a stylized swarm representing the smaller, irregular moons.

🏷️ Labels: A toggle function for moon labels.

While this tool is meant to be an illustrative visualization, not a scientific dataset, its features provide a rich and interactive way to explore the Jupiter system.
